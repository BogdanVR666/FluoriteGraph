# Операції над структурами FluoriteGraph

Повний перелік того, що можна зробити з кожним об'єктом у поточному стані `src/fluoritegraph/graph.py`.

**Позначення**

- **API** — операція є методом бібліотеки. **Напряму** — це звичайна операція з полем, словником або множиною, яку бібліотека нічим не обмежує.
- **N_t** — кількість вершин у типі, **E_t** — кількість ребер у типі, **E** — усі ребра графа, **H** — усі гіперребра,
  **T** — кількість типів (`T_n` вершин, `T_e` ребер), **k** — кількість переданих елементів.
- `replace` — це `dataclasses.replace`. Сутності незмінні, тож «змінити» означає «замінити об'єкт з тим самим `id`».
- Складність словників і множин указано в середньому.

---

## Ідентифікатори (`_counter`)

| Операція | Як | Складність | Спосіб | Примітки |
|---|---|---|---|---|
| Отримати новий `id` | `next(_counter)` | O(1) | Напряму | `_counter` приватний. Його викликають конструктори `Node`, `Edge`, `Hyperedge` |
| Дізнатися, чим є `id` | перебір типів | O(T_n + T_e + 1) | Напряму | Сам `id` про це нічого не каже |
| Повторно використати `id` | — | — | — | Неможливо: лічильник тільки зростає, видалені `id` пропадають |
| Скинути / продовжити після завантаження | — | — | — | API немає. Це питання серіалізації |

Один лічильник на всі сутності (вершини, ребра, гіперребра), тож `id` унікальні в межах процесу.

## `FluoriteGraph`

| Операція | Як | Складність | Спосіб | Примітки |
|---|---|---|---|---|
| Створити | `FluoriteGraph(nodes=..., edges=..., hyperedges=...)` | O(T + H) | API | `nodes` / `edges` — словники або списки. Списки перетворюються на словник за `name`; однакові імена тихо перезаписуються. Гіперребра (список або словник) проходять через `hyperadd` |
| Отримати тип вершин / ребер за назвою | `graph.nodes[name]`, `graph.edges[name]` | O(1) | Напряму | |
| Перебрати типи | `graph.nodes.values()`, `graph.edges.values()` | O(T) | Напряму | |
| Додати тип після створення | `graph.nodes[t.name] = t` | O(1) | Напряму | API немає. Ключ ставиться вручну і може не збігатися з `t.name`; однакова назва перезапише наявний тип |
| Видалити тип | `del graph.nodes[name]` | O(1) | Напряму | Усі `id` його сутностей лишаються висячими в ребрах і гіперребрах |
| Перейменувати тип | `graph.nodes[new] = NodeType(new, old.nodes)`; `del graph.nodes[old_name]` | O(1) | Напряму | Новий тип ділить словник `nodes` зі старим |
| Знайти сутність за `id` будь-якого виду | перебір `graph.nodes`, `graph.edges`, `graph.hyperedges` | O(T_n + T_e + 1) | Напряму | Тип і об'єкт знаходяться одним пошуком |
| Додати гіперребро | `graph.hyperadd(hyperedge)` | O(піддерев дітей) | API | Виставляє `owner`. Цикл серед уже наявних дітей — `ValueError` |
| Додати кілька гіперребер | `graph.hyperextend([...])` | Σ `hyperadd` | API | |
| Вставити гіперребро в обхід перевірки | `graph.hyperedges[he.hyperedge_id] = he` | O(1) | Напряму | `owner` не виставляється, DAG не перевіряється |
| Отримати гіперребро за `id` | `graph.hyperedges[id]` | O(1) | Напряму | |
| Отримати гіперребро за назвою | перебір `graph.hyperedges` | O(H) | Напряму | Методу немає |
| Перебрати / порахувати гіперребра | `graph.hyperedges.values()`, `len(graph.hyperedges)` | O(H) / O(1) | Напряму | Це і є «усі групи» |
| Видалити гіперребро | `del graph.hyperedges[id]` | O(1) | Напряму | `id` лишається висячим у `children` інших гіперребер; перевірка на DAG вважає його листком. `owner` видаленого гіперребра і далі вказує на граф |
| Знайти гіперребра, які містять `id` | перебір `graph.hyperedges` | O(H) | Напряму | Це ж — пошук батьків гіперребра |
| Перевірити досяжність | `graph._reaches(start, target)` | O(піддерева) | Внутрішнє | Використовується в `hyperadd` і `Hyperedge.append` |
| Вивести | `print(graph)` / `repr(graph)` | O(розміру графа) | API | Згенерований dataclass |

## `NodeType`

| Операція | Як | Складність | Спосіб | Примітки |
|---|---|---|---|---|
| Створити | `NodeType(name)` / `NodeType(name, nodes)` | O(1) | API | Іменований аргумент — `_name=` |
| Прочитати назву | `t.name` | O(1) | API | Властивість лише для читання |
| Змінити назву | `t.name = ...` | — | — | `AttributeError`. `t._name = ...` спрацює, але ключ у графі не зміниться |
| Створити вершину | `t.append(name, description=None)` | O(1) | API | Нічого не повертає |
| Створити кілька вершин | `t.extend([...])` | O(k) | API | Елемент — `"name"` або `("name", "description")`, інакше `ValueError` |
| Вставити готовий `Node` | `t.nodes[node.node_id] = node` | O(1) | Напряму | |
| Отримати вершину за `id` | `t.nodes[id]` | O(1) | Напряму | `KeyError`, якщо немає |
| Отримати вершину за назвою | `t[name]` | O(N_t) | API | Повертає `Node`, `list[Node]` (тезки) або `KeyError`. Лінійний перебір навмисний |
| Перевірити наявність `id` | `id in t.nodes` | O(1) | Напряму | |
| Перебрати / порахувати | `t.nodes.values()`, `len(t.nodes)` | O(N_t) / O(1) | Напряму | |
| Змінити вершину | `t.nodes[id] = replace(t.nodes[id], name=...)` | O(1) | Напряму | `id` зберігається; ребра й гіперребра не зачіпаються |
| Перенести вершину в інший тип | `other.nodes[id] = t.nodes.pop(id)` | O(1) | Напряму | `id` зберігається |
| Видалити вершину | `del t.nodes[id]` | O(1) | Напряму | `id` лишається висячим у ребрах (O(E), щоб знайти) і в гіперребрах (O(H)) |

## `NodeType.Node`

| Операція | Як | Складність | Спосіб | Примітки |
|---|---|---|---|---|
| Створити напряму | `NodeType.Node(name, description)` | O(1) | API | Бере `id` з лічильника, але в жоден тип не потрапляє |
| Прочитати поля | `name`, `description`, `node_id` | O(1) | Напряму | |
| Змінити поле | `node.name = ...` | — | — | `FrozenInstanceError`. Замість цього — `replace` |
| Порівняти / хешувати | `==`, `hash()` | O(1) | API | За всіма полями: `name`, `description`, `node_id` |
| Знайти тип вершини | перебір `graph.nodes` | O(T_n) | Напряму | Вершина не знає свого типу |
| Знайти ребра вершини (сусідів) | перебір усіх ребер | O(E) | Напряму | Зворотних індексів немає |
| Знайти гіперребра, які містять вершину | перебір гіперребер | O(H) | Напряму | |

## `EdgeType`

| Операція | Як | Складність | Спосіб | Примітки |
|---|---|---|---|---|
| Створити | `EdgeType(name, directed=False)` | O(1) | API | Іменований аргумент — `_name=` |
| Прочитати назву | `t.name` | O(1) | API | Лише для читання, як у `NodeType` |
| Прочитати / змінити напрямленість | `t.directed`, `t.directed = True` | O(1) | Напряму | Змінює напрям одразу для всіх ребер типу |
| Створити ребро | `t.append(node_in, node_out)` | O(1) | API | Приймає `id`. Опис задати не можна. Існування `id` не перевіряється. Нічого не повертає |
| Додати кілька ребер | `t.extend([...])` | O(k) | API | Елемент — готовий `Edge` (вставляється як є, з описом) або пара `id`, інакше `ValueError` |
| Вставити готовий `Edge` | `t.edges[edge.edge_id] = edge` | O(1) | Напряму | |
| Отримати ребро за `id` | `t.edges[id]` | O(1) | Напряму | |
| Перебрати / порахувати | `t.edges.values()`, `len(t.edges)` | O(E_t) / O(1) | Напряму | |
| Знайти ребра між двома `id` | перебір `t.edges` | O(E_t) | Напряму | |
| Змінити ребро (кінці, опис) | `t.edges[id] = replace(t.edges[id], node_out=...)` | O(1) | Напряму | На ребра ніщо не посилається |
| Перенести ребро в інший тип | `other.edges[id] = t.edges.pop(id)` | O(1) | Напряму | Змінює «вид» зв'язку |
| Видалити ребро | `del t.edges[id]` | O(1) | Напряму | Висячим `id` ребра може лишитися лише там, куди його поклали вручну (кінець іншого ребра, `children`) |

## `EdgeType.Edge`

| Операція | Як | Складність | Спосіб | Примітки |
|---|---|---|---|---|
| Створити напряму | `EdgeType.Edge(node_in, node_out, description)` | O(1) | API | Єдиний спосіб створити ребро з описом (далі — через `extend`) |
| Прочитати поля | `node_in`, `node_out`, `description`, `edge_id` | O(1) | Напряму | Кінці — `id`. Кінцем може бути будь-яка сутність, зокрема гіперребро |
| Отримати вершину-кінець | `graph.nodes[type].nodes[edge.node_in]` або перебір типів | O(1) / O(T_n) | Напряму | |
| Змінити поле | `edge.node_in = ...` | — | — | `FrozenInstanceError`. Замість цього — `replace` |
| Порівняти / хешувати | `==`, `hash()` | O(1) | API | За всіма полями |

## `Hyperedge`

| Операція | Як | Складність | Спосіб | Примітки |
|---|---|---|---|---|
| Створити | `Hyperedge(name, description=None, children=set())` | O(1) | API | `owner` порожній, доки гіперребро не додано в граф |
| Прочитати поля | `name`, `description`, `hyperedge_id`, `children`, `owner` | O(1) | Напряму | |
| Змінити назву / опис | `he.name = ...`, `he.description = ...` | O(1) | Напряму | Клас змінний, назва ніде не є ключем |
| Змінити `hyperedge_id` | `he.hyperedge_id = ...` | O(1) | Напряму | Технічно можна, але ключ у `graph.hyperedges` і посилання в `children` інших гіперребер лишаться старими |
| Додати дитину | `he.append(child_id)` | O(піддерева дитини) | API | Дитина — вершина або гіперребро. На цикл чи на себе — `ValueError`. Без `owner` перевіряється лише додавання самого себе. Існування `id` не перевіряється |
| Додати кілька дітей | `he.extend([...])` | Σ `append` | API | |
| Додати дитину в обхід перевірки | `he.children.add(id)`, `he.children.update(...)` | O(1) / O(k) | Напряму | Може тихо створити цикл |
| Прибрати дитину | `he.children.discard(id)` / `.remove(id)` | O(1) | Напряму | Безпечно: видалення не створює циклу |
| Перевірити належність | `id in he.children` | O(1) | Напряму | Лише прямі діти |
| Порахувати дітей | `len(he.children)` | O(1) | Напряму | Лише прямі діти |
| Об'єднання / перетин / різниця | `a.children \| b.children`, `&`, `-` | O(розміру множин) | Напряму | Лише прямі діти; вкладені гіперребра входять як `id`, а не як їхній вміст |
| Отримати всі вершини разом із вкладеними | обхід вручну | O(піддерева) | Напряму | Методу немає |
| Скопіювати як окрему групу | `Hyperedge(name, children=set(he.children))` + `graph.hyperadd(...)` | O(розміру множини) | API | Новий `id`; множину треба копіювати, інакше вона буде спільною |
| Перенести в інший граф | `other.hyperadd(he)` | O(піддерев дітей) | API | `owner` переходить на новий граф. Якщо гіперребро лишилося в старому графі, перевірка там іде вже через чужий граф |
| Порівняти | `==` | O(розміру `children`) | API | Без `owner`. Клас змінний, тож не хешується |
